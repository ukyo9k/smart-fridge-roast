One line, at most 160 characters, roasting the smart fridge — or any smart
home gadget the writer lives with. This entry goes after a real feature
nobody asked to be judged by: the camera inside the fridge, which lets you
check what's in it from the store and mostly shows you the same three
condiments, judging you in 1080p.

## The line

> My smart fridge has a camera inside so I can check what's in it from the store — it mostly shows me the same three condiments, judging me in 1080p.

147 characters.

## Run it

```bash
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
# writes /tmp/out/entry.txt and validates it:
# UTF-8, 1–160 chars, single line, no control chars, read-back round-trip
```
